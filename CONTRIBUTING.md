# Contributing

- One entry per PR, alphabetical within its section where practical.
- Format: `[name](url) - What it is and why it matters for agent security (one line).`
- Must be agent-security specific: skills/plugins/MCP/hooks/runtime/red-teaming for autonomous agents. Generic infosec or generic ML belongs elsewhere.
- No dead links, no vendor marketing pages without substance.
- New sections need 3+ entries to justify themselves.
